One funny, true line reviewing the most boring everyday object: the doorstop.

> The doorstop does one job, never complains, and has never once been thanked. Five stars. It holds the door and my respect.

## Run

```sh
node main.ts
```

Reads the entry from `entry.txt` and writes it to `output/entry.txt`
(or the directory in `MAKEFUN_OUTPUT_DIR` / `MAKEFUN_BOT_DIR`).
Node 22, stdlib only, no network, no wall clock.
